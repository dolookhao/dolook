# 灵犀 AI 视频营销 Agent

> 演示内容｜该案例、日期、指标及组织均为虚构，仅用于作品集视觉展示。

**让六类智能体协同完成从选题到内容交付**

- 类型：AI Agent
- 职责：平台产品经理（模拟）
- 时间：2025.01—2025.08（模拟）
- 技术/业务关键词：Agent / Workflow / 多模型 / 内容生产

## 项目概述

构建多智能体营销工作台，把趋势研究、创意策划、脚本、分镜、审核和发布串联成可追踪流程。

## 业务问题

团队跨工具复制资料，审核链断裂，过程信息缺少可追溯的统一记录。

## 我的产品方案（模拟）

1. 将大任务拆成研究、策划、生产、审校四个阶段。
2. 定义六类角色的输入、输出、失败重试和人工审批点。
3. 设计任务看板与版本回滚，避免内容被不可控地覆盖。

## 核心展示指标（模拟）

- **6**：模拟智能体角色
- **42%**：模拟耗时下降
- **4**：协作流程阶段

## 可视化展示建议

Agent 流程画布、任务执行面板、脚本审核页

## 成果与复盘（模拟）

模拟结果：内容制作准备耗时下降约 42%，并建立逐段验收记录。
