# 关于我（演示）

> 页面介绍为模拟表达，不作为求职履历。

这是一份用模拟资料构建的网站展示文本。页面结构体现平台型产品经理的典型能力：理解市场与用户、规划业务边界、推进交付，以及用可验证的指标进行迭代。

在实际项目中，产品管理的难点往往不是功能数量，而是资源有限时的判断与取舍。展示案例因此会包含背景、限制条件、不同方案的权衡和复盘。

正式版本将替换为站长本人已核实的教育经历、任职信息、项目成果和可公开的附件。

## 产品方法

需求洞察 → 问题拆解 → 方案权衡 → PRD 与协同 → 上线验收 → 数据复盘。
